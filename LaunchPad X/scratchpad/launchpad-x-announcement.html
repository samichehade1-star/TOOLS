02

How it's built

Three launch protocols, generalized from tools already in daily use, cover almost everything a trainer throws at you.

  • Direct path
    Points straight at a known .exe and runs it. For tools that never move or rename themselves.
  • Folder scan
    Some tools rename their executable on every update. LaunchPad X watches the folder and launches whatever shows up, elevating silently once you've approved it the first time.
  • Extract & retry
    For tools shipped as archives: unpacks the .zip/.7z/.rar, waits for the extracted executable to appear, and retries if the first attempt is too early.
  • Platform protocols
    For games themselves — steam://, Epic, Ubisoft, and Xbox launch URIs are used ahead of any direct exe path, so the real client handles the launch.

    How to use it

    1

    Install

    Run LaunchPad X Setup 1.0.0.exe. It's a standalone Windows installer — no dependencies, no dev configuration bundled in.

    2

    Let it find your games

    Open Settings → Scan & Import. LaunchPad X checks Steam, Epic, Ubisoft Connect, Roblox, and Xbox for what's installed and adds them to your Library with cover art.

    Missing a game? Add it manually from the same screen.
    3

    Add a tool to a game

    Open a game, hit + Add Tool. Reuse one you've already set up elsewhere, or create a new one: point it at a file or folder, and tell it whether it needs extraction, a retry, or a UAC prompt.

    4

    Launch

    Click the tool's card. LaunchPad X runs whatever sequence you configured — elevation, extraction, retries — and reports back if something needs your attention.

    5

    Arrange it your way

    Drag games and tools to reorder them, hide the ones you're not using, and tune the color theme from Settings whenever you like.
